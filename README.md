# Guilherme Nascimento — personal site

Personal digital garden of Guilherme Nascimento: articles, notes, and a `/now` page.

**Live:** [https://vilih.com](https://vilih.com) (`/en` and `/pt-br`)

## Stack

- [Astro](https://astro.build/) (static site)
- MDX content collections
- Light / dark theme toggle

## Run locally

```sh
pnpm install
pnpm dev
```

Open [http://localhost:4321](http://localhost:4321) (redirects to `/en`).

```sh
pnpm build    # production build → ./dist/
pnpm preview  # preview the build
```
